Это данные из API BlockCypher о транзакциях по биткоин‑адресу — они описывают, как менялся баланс: какие входы/выходы были, сколько подтверждений и т. п.

Расшифровка полей
tx_hash — хеш транзакции (уникальный ID). По нему можно найти транзакцию в обозревателе блокчейна.
block_height — высота блока, в который включена транзакция (номер блока в цепи). Чем больше, тем «старее» блок.
tx_input_n — номер входа (input) в транзакции, который относится к этому адресу.
0, 1 и т. д. — конкретный вход.
-1 — значит, что для этого адреса это не вход, а выход (то есть адрес получил средства, а не потратил). BlockCypher так помечает «не свой вход».
tx_output_n — номер выхода (output) транзакции, который относится к адресу.
0, 1 и т. д. — конкретный выход на адрес.
-1 — для этого адреса это не выход, а вход (адрес потратил средства).
value — сумма в сатоши (1 BTC = 100 000 000 сатоши). Это именно сумма по конкретному входу/выходу, а не итоговый баланс.
ref_balance — баланс адреса после этой операции (в сатоши). То есть это накопленный итог: сколько всего осталось на адресе после учёта этой записи.
confirmations — количество подтверждений (сколько блоков построено поверх того, где лежит транзакция). Чем больше — тем безопаснее считать транзакцию окончательной.
confirmed — дата и время, когда транзакция была включена в блок (UTC).
double_spend — флаг двойного расходования. false значит, что двойного расхода нет, транзакция валидна.
spent (есть не во всех записях) — потрачен ли этот выход. true значит, что эти монеты уже использованы в другой транзакции.
spent_by — хеш транзакции, которая потратила этот выход.

Это цепочка из двух связанных транзакций:

Первая запись (вход №1, value: 1290): часть средств пришла на адрес (1290 сатоши), баланс стал ref_balance: 0 (тут может быть особенность расчёта в API или округление/учёт других операций).
Вторая запись (вход №0, value: 76247): ещё одна часть прихода (76247 сатоши), после чего баланс стал ref_balance: 1290.
Третья запись — это расход (выход на адрес, потом потрачен):
Выход на адрес на сумму 76247 сатоши.
Потом этот выход был потрачен в транзакции d040b6e9… (это первая транзакция из списка).
Поле spent: true и spent_by прямо указывают, куда ушли монеты.
То есть BlockCypher показывает не просто «пришло/ушло», а детально по входам и выходам, чтобы можно было точно отследить движение средств и избежать двойного расходования.
